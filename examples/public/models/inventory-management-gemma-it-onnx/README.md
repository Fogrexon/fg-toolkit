# Fine-tuned Model Setup

This directory is intended to house the fine-tuned ONNX model files for the "Inventory Management" demo.
Because the model files are large, they are not included in the git repository.

## Instructions

1.  **Obtain the Model**: 
    - You should have the fine-tuned ONNX model files (generated by the `trainer` or downloaded).
    - The expected files are: `model.onnx`, `config.json`, `tokenizer.json`, etc.

2.  **Place Files**:
    - Copy all ONNX model files into this directory: `examples/public/models/inventory-management-gemma-it-onnx/`.

3.  **License Compliance**:
    - Ensure you comply with the [Gemma Terms of Use](https://ai.google.dev/gemma/terms) when using or redistributing these models.
    - You must include the `NOTICE` file and strict adherence to the Prohibited Use Policy.

Once the files are in place, the `fine-tuned-chat` example will be able to load the model from this location.
